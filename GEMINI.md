# Paridhan Boutique Website Project

This folder contains the source code and assets for the **Paridhan Boutique** official website.

## Business Details
- **Owner:** Sapna Parashar
- **Established:** 2012
- **Location:** 67 Patel Nagar, near Bindal Showroom, City Centre, Gwalior
- **Contact:** +91 9753834831 (WhatsApp integrated)
- **Hours:** 12:00 PM - 9:30 PM Daily
- **Tagline:** आओ कुछ अलग पहनें

## Design System
- **Theme:** Luxury Fashion Boutique
- **Colors:** 
  - Dark Pink (`#ad1457`)
  - Pink Accent (`#d81b60`)
  - Cream/Light Cream (`#fff9c4`, `#fffde7`)
  - Background: Dynamic Gradient between Cream and Rose Pink (`#f8bbd0`)

## Key Features
- **Hero Section:** Full-bleed background using `marble logo2.png` with centered branding.
- **Our Services:** Interactive cards for Sarees, Lehengas, Custom Stitching, Ethnic Fusion, and Salwar Suits.
- **Galleries:**
  - **Collection:** 35 custom-stitched model photos (`cloth1.png` - `cloth35.png`).
  - **Interior:** 19 boutique interior views (`boutique interior1.png` - `boutique interior19.png`).
- **Interactive Lightbox:** Any image on the site can be clicked to enlarge with a blurred background effect.
- **Social Integration:** Embedded Instagram Reel and direct link to `@paridhan.1`.

## File Structure
- `index.html`: The main website file (HTML/CSS/JS combined).
- Asset naming follows strict patterns: `cloth[N].png`, `boutique interior[N].png`, `boutique exterior[N].png`.
